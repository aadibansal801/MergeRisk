What the labels mean

Textually clean means Git combined the lines. No supported findings means no supported rule found an issue. Partial means some references or constructs could not be resolved. Static verified applies to the checked candidate edits. Runtime verified is used only when explicitly configured isolated checks actually pass. None of these labels guarantees arbitrary program behavior.
