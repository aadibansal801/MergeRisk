# Week 5 — Present the integration sequence

Journal week: 12–18 September 2026

Source record period: 14–17 September 2026

For the review I followed the arrows in the sequence diagram and described who produced the combined source. At the time we could hand the prototype the four versions. In the repository version, Git itself had to supply the combined one. It was easy to blur the distinction if I just called all of it “the merge.”

The takeaway for my part was a test I could actually run later: create a small repository and check which tree comes back, then check that the analyzer got its contents without moving the checkout. It was a useful first target because it covered the integration without requiring us to finish the whole report UI.
