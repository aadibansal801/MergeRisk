# Week 12 — Map the local prototype interface

Journal week: 31 Oct–6 Nov 2026

Source record period: 4–16 November 2026

The local dashboard was our chance to use the same analysis result in two very different places. The CLI could print it, while FastAPI and Jinja could render it with a little JavaScript for interaction. I wanted the page to use the service's explanation wherever it was available rather than make up its own reasons.

When we moved to the hosted beta, a person entered through sign-in and pasted a public GitHub repository. After that, the familiar steps were choosing branches and reading the evidence. Keeping those parts recognizable helped me decide what to carry over from the local dashboard. The hosted comparison had a different way in, but the review task still fit on one page.
