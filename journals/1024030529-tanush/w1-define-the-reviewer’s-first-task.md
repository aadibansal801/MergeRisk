# Week 1 — Define the reviewer’s first task

Journal week: 15–21 August 2026

Source record period: 15–30 August 2026

I imagined opening the tool after Git told me the branches could be merged. I wouldn't want a general warning at that point. I'd want a line to open and an idea of what had happened. The invoice example made that concrete: `print_invoice` still passes two arguments, and `calculate_total` now needs another one.

For the first terminal report, I wanted the call and the changed definition close together. If a developer can look at the result and repeat that explanation in a review comment, the output has done its job. That was the part I wanted to keep when we started talking about screens instead of terminal output.
