# Week 4 — Use four snapshots to explain a finding

Journal week: 5–11 September 2026

Source record period: 31 August–14 September 2026

I used to describe the four snapshots as “before, both sides, and after,” which was fine until I had to explain who was merging into whom. In our invoice walkthrough the base gives me the old definition, each parent shows its contribution, and the candidate shows them together.

The labels needed to make the direction visible in the form itself. Target is where the changes will go. Source is where they're coming from. In the hosted version, the diagram puts both branches around the preview so I can check the direction before submitting. It's a small detail, but if I get those fields backward, I'm reviewing a different comparison.
